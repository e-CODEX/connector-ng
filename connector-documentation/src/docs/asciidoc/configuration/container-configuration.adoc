= Container configuration

This configuration defines the cryptographic settings used by the connector security library for:

* Token generation (PDF and XML)
* ASIC-S container signing
* Validation of the signatures found in containers

== Basic configuration
Configuration is provided via `application.properties` under the `connector.container.*` prefix.

NOTE: The configuration is validated at startup. A missing or blank mandatory value stops the
connector with an error naming the offending property.

== Signature configuration

.Container Signature Configuration Properties
[cols="35,40,10,15"]
|===
| Property | Description| Optional | Example

| `connector.container.signature.keystore.path`
| Path to the Java KeyStore holding the private key/certificate used to SIGN containers.
Use the `file:` or `classpath:` prefix.
| No
| `file:./config/keystores/connector-keystore.jks`

| `connector.container.signature.keystore.password`
| Password protecting the keystore file itself.
| No
| `${CONTAINER_KEYSTORE_PASSWORD}`

| `connector.container.signature.keystore.type`
| Keystore format. JKS is the legacy Java format; PKCS12 is also supported
| Yes
| `JKS`. By default, set to *JKS*

| `connector.container.signature.private-key.alias`
| Alias identifying which key entry inside the keystore to use for signing
| No
| `connector_blue`

| `connector.container.signature.private-key.password`
| Password protecting that specific private key entry
| No
| `${CONTAINER_KEY_PASSWORD}`

| `connector.container.signature.digest-algorithm`
| Digest algorithm used when signing.
| Yes
| `SHA256`. By default, set to *SHA256*

| `connector.container.signature.encryption-algorithm`
| Encryption algorithm of the signing key.
| Yes
| `RSA`. By default, set to *RSA*
|===

.Configuration Example
[source,properties]
----
connector.container.signature.keystore.path=file:./config/keystores/connector-keystore.jks
connector.container.signature.keystore.password=${CONTAINER_KEYSTORE_PASSWORD}
connector.container.signature.keystore.type=JKS
connector.container.signature.private-key.alias=connector_blue
connector.container.signature.private-key.password=${CONTAINER_KEY_PASSWORD}
connector.container.signature.digest-algorithm=SHA256
----

== Signature validation configuration

Properties under `connector.container.signature.validation.*` control how signatures in containers are validated.

.Container Signature Validation Properties
[cols="35,40,10,15"]
|===
| Property | Description| Optional | Example

| `connector.container.signature.validation.constraints-xml`
| Validation policy (constraints) file applied when validating signatures.
Accepts a `classpath:` or `file:` location. The file must exist, otherwise the startup fails.
| Yes
| `classpath:/102853/constraint.xml`. By default, set to *classpath:/102853/constraint.xml*

| `connector.container.signature.validation.ocsp-enabled`
| Whether OCSP is queried when verifying certificates.
| Yes
| `true`. By default, set to *true*

| `connector.container.signature.validation.crl-enabled`
| Whether CRLs are queried when verifying certificates.
| Yes
| `true`. By default, set to *true*

| `connector.container.signature.validation.aia-enabled`
| Whether the Authority Information Access extension is used to find issuer certificates.
| Yes
| `true`. By default, set to *true*

| `connector.container.signature.validation.truststore-enabled`
| Whether the configured truststore is used. If `true`, the `truststore.*` block must be configured.
| Yes
| `true`. By default, set to *true*

| `connector.container.signature.validation.truststore.path` / `.password` / `.type`
| Truststore with the trusted certificates. `path` and `password` are required when the block is present, `type` defaults to `JKS`.
| Yes
| `file:./config/keystores/connector-truststore.jks`

| `connector.container.signature.validation.ignore-store-enabled`
| Whether the configured ignore store is used. If `true`, the `ignore-store.*` block must be configured.
| Yes
| `false`. By default, set to *false*

| `connector.container.signature.validation.ignore-store.path` / `.password` / `.type`
| Store with certificates to ignore during validation. `path` and `password` are required when the block is present, `type` defaults to `JKS`.
| Yes
| `file:./config/keystores/connector-ignore.jks`

| `connector.container.signature.validation.trusted-list-source`
| Name of a trust source configured under `connector.dss.trust-list-sources.*`, used as trusted list source for validation.
| Yes
| `eu`
|===

.Configuration Example
[source,properties]
----
connector.container.signature.validation.constraints-xml=classpath:/102853/constraint.xml
----
