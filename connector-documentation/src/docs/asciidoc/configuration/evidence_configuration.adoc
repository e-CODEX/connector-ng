== REM Evidence Configuration

The connector generates ETSI-REM evidences for message lifecycle events.
Generated evidences are electronically signed (XAdES) and include mandatory issuer metadata.

Configuration is provided via `application.properties` under the `connector.evidences.*` prefix.

=== Signature configuration

Properties under `connector.evidences.signature.*` control how REM evidence XML is signed.

.ETSI-REM Evidences Signature Configuration Properties
|===
| Property | Description | Example

| `connector.evidences.signature.payload-digest-algorithm`
| Digest algorithm used when hashing the business payload referenced by the evidence.
| `SHA256`

| `connector.evidences.signature.keystore.path`
| Classpath or filesystem path to the keystore holding the signing private key.
| `classpath:keystores/connector-keystore.jks`

| `connector.evidences.signature.keystore.password`
| Password for the keystore.
| *(secret)*

| `connector.evidences.signature.keystore.type`
| Keystore type (for example `JKS` or `PKCS12`).
| `JKS`

| `connector.evidences.signature.private-key.alias`
| Alias of the private key within the keystore. The corresponding public key must be shared with communication partners.
| `connector_blue`

| `connector.evidences.signature.private-key.password`
| Password to unlock the private key entry.
| *(secret)*

|===

=== Issuer configuration

Properties under `connector.evidences.issuer.*` are embedded into generated REM evidences.

.Issuer Configuration Properties
|===
| Property | Description | Example

| `connector.evidences.issuer.postal-address.street`
| Issuer street address (mandatory for evidence building).
| `Unknown Street 1`

| `connector.evidences.issuer.postal-address.locality`
| Issuer locality.
| `Unknown`

| `connector.evidences.issuer.postal-address.zip-code`
| Issuer postal code.
| `0000`

| `connector.evidences.issuer.postal-address.country`
| Issuer country.
| `EU`

| `connector.evidences.issuer.as4-party.name`
| AS4 party name of the gateway over which evidences are sent (home party in PMode configuration).
| `Connector Gateway`

| `connector.evidences.issuer.as4-party.endpoint-address`
| AS4 endpoint address of the evidence issuer gateway.
| `mailto:gateway@connector.example`

|===

=== Message processing options

|===
| Property | Description | Default

| `connector.message-processing.send-generated-evidences-to-backend`
| When `true`, generated evidences are also forwarded to the backend after submission to the gateway.
| `true`

| `connector.queues.outbound-evidence-trigger-queue`
| JMS queue for outbound evidence trigger messages received from the backend.
| `connector.queues.outbound-evidence-trigger-queue`

|===
