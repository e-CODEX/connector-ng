= Business Domain Configuration

The connector supports one or more business domains.
A business domain defines a logical runtime context used by the connector, including the associated PMode configuration file.

If no business domain is explicitly configured, the connector automatically creates a default domain during startup.

== Basic configuration
Configuration is provided via `application.properties` under the `connector.connector.business-domains.*` prefix.

.Business Domains Configuration
[cols="35,40,10,15", options="header"]
|===
| Property | Description | Optional | Example

| `connector.business-domains.defaults[0].identifier`
| Unique identifier for this business domain. Business domains let a single connector instance logically partition message processing, routing, and configuration (e.g. multi-tenant setups) — this is the key used to reference this domain elsewhere.
| No
| `default_business_domain`

| `connector.business-domains.defaults[0].description`
| Free-text human-readable description of the business domain.
| No
| `default business domain`

| `connector.business-domains.defaults[0].enabled`
| Whether this business domain is active. Disabled domains can't process messages even if referenced elsewhere.
| No
| `true`

| `connector.business-domains.defaults[0].pmode`
| Path to the AS4 Processing Mode (P-Mode) XML file governing message exchange behavior (security, reliability, MEP, etc.) for this domain. If not configured through the properties file, the processing mode (Pmode) for a business domain can also be loaded via the following `REST` endpoint: `POST` `/api/v1/admin/processing-modes`. Refer to the autogenerated Swagger documentation for detailed usage instructions and request examples.
| Yes
| `file:./config/pmode/pmode-blue.xml`

|===

.Configuration Example
[source,properties]
----
connector.business-domains.defaults[0].identifier=default_business_domain
connector.business-domains.defaults[0].description=default business domain
connector.business-domains.defaults[0].enabled=true
connector.business-domains.defaults[0].pmode=file:./config/pmode/pmode-blue.xml
----
